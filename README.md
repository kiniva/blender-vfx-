# 專案使用說明 (README)

請依照以下步驟環境設定與開啟專案，以確保模型與材質等資產能正常載入。

## 1. 下載並安裝 Blender
若您的電腦尚未安裝 Blender，請先前往 [Blender 官方網站](https://www.blender.org/download/) 下載適合您作業系統的版本並完成安裝。

## 2. 下載專案檔案
請確保您已將以下兩個檔案下載至同一個資料夾中：
* `file.blender` （主要專案檔）
* `file.blender1` （備份檔）

## 3. 開啟專案

### 從 Blender 內部開啟
1. 先開啟 Blender 軟體。
2. 透過左上角選單點擊 **「檔案 (File)」 > 「開啟 (Open)」**。
3. 選擇並匯入 `file.blender`。
